# Kyaw Thu Win — Portfolio

A personal portfolio for showcasing Kyaw Thu Win’s education, skills, academic projects, and contact details. The design follows a minimalist, dark brown and cream palette with responsive layouts, scroll reveals, and a desktop cursor effect.

## Tech stack

- React 19 and TypeScript
- Vite 7
- Lucide React icons
- CSS variables and responsive CSS

## Getting started

Requirements: Node.js 20 or newer and npm.

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

Portfolio content is maintained in `src/data/portfolio.ts`. Place the profile photo and CV in `Public/`, then update their paths in that configuration. The color palette is defined by CSS variables at the top of `src/styles.css`.
